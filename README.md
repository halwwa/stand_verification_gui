# Стенд автоматизированной поверки радиоприборов

GUI-приложение для автоматизированной поверки измерительных приборов
(СК3-50, С6-22, SMB100A) с сохранением отчётов в Excel.

## Что умеет

- Подключение к приборам:
  - **СК3-50** — через COM-порт (115200 бод).
  - **С6-22** — через COM-порт (9600 бод).
  - **SMB100A** — через LAN (TCPIP, порт 5025).
- Автозаполнение данных тестируемого прибора (модель, серийный номер) из `*IDN?`.
- **12 поверочных тестов:**

| № | Тест | Приборы |
|---|---|---|
| 1 | Погрешность измерения частоты входного сигнала | СК3-50, SMB100A |
| 2 | Погрешность измерения уровня | СК3-50, SMB100A |
| 3 | АМ шум | СК3-50, SMB100A |
| 4 | ЧМ шум | СК3-50, SMB100A |
| 5 | ФМ шум | СК3-50, SMB100A |
| 6 | Переход АМ↔ЧМ | СК3-50, SMB100A |
| 7 | КГ АМ | СК3-50, С6-22, SMB100A |
| 8 | КГ ЧМ | СК3-50, С6-22, SMB100A |
| 9 | Проверка линейности шкал ЧМ | СК3-50, SMB100A |
| 10 | Погрешность пиковых значений девиации ЧМ | СК3-50, SMB100A |
| 11 | Погрешность пиковых значений Кам (АМ) | СК3-50, SMB100A |
| 12 | Погрешность пиковых значений индекса ФМ | СК3-50, SMB100A |

- Цветовая индикация результатов: 🟢 Пройден / 🟡 Внимание / 🔴 Провален.
- Диалог при провале: «Продолжить / Остановить».
- Сохранение отчёта в Excel — отдельный лист для каждого теста.
- Лог с возможностью сохранения в файл.

## Требования

- **Windows 10 или 11** (протестировано на Windows 11).
- **Python 3.11+** (для запуска из исходников).
- **Приборы** — подключены к компьютеру:
  - СК3-50 — по COM-порту.
  - С6-22 — по COM-порту (опционально, нужен для тестов 7, 8).
  - SMB100A — по LAN.

## Установка (из исходников)

```bat
git clone https://github.com/halwwa/stand_verification_gui.git
cd stand_verification_gui
pip install -r requirements.txt
```

## Запуск

```bat
python gui_stand.py
```

Откроется окно «Стенд автоматизированной поверки радиоприборов».

## Сборка `.exe`

```bat
python -m PyInstaller --noconfirm --onefile --windowed ^
    --name "StandGUI" ^
    --collect-all pyvisa ^
    --collect-all pyvisa_py ^
    --collect-all serial ^
    --collect-all openpyxl ^
    --hidden-import serial.tools.list_ports ^
    --add-data "stand_verification;stand_verification" ^
    gui_stand.py
```

Готовый файл: `dist/StandGUI.exe` (~40–50 МБ).

## Как пользоваться

1. Подключите приборы (через карточки в окне):
   - **СК3-50** — выберите COM-порт и 115200 бод → «Подключить».
   - **С6-22** — выберите COM-порт и 9600 бод → «Подключить».
   - **SMB100A** — введите IP и порт 5025 → «Подключить».
2. В блоке «Тестируемый прибор» — проверьте данные (заполняются автоматически).
3. В списке тестов — отметьте нужные галочками.
4. Нажмите **«▶ СТАРТ ВСЕХ ВЫБРАННЫХ ТЕСТОВ»**.
5. Дождитесь завершения. Отчёт Excel сохранится в папку «Путь сохранения».

## Технологии

- **GUI:** `tkinter` (встроен в Python).
- **Приборы:** `pyvisa`, `pyvisa-py` (LAN), `pyserial` (COM).
- **Отчёты:** `openpyxl`.
- **Сборка:** `pyinstaller`.
